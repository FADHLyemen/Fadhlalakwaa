# Fadhl M. Alakwaa, PhD — Personal Academic Website

A professional academic website for [Fadhl M. Alakwaa, PhD](https://alakwaa.github.io), Assistant Research Scientist at the University of Michigan, Department of Internal Medicine — Nephrology.

## 🚀 Deploy to GitHub Pages (5 minutes)

### Step 1: Create the repository
1. Go to [github.com/new](https://github.com/new)
2. Name the repository: `alakwaa.github.io` (replace `alakwaa` with your GitHub username)
3. Set to **Public**
4. Click **Create repository**

### Step 2: Upload files
1. Click **"uploading an existing file"** on the new repo page
2. Drag and drop `index.html` into the upload area
3. Click **Commit changes**

### Step 3: Enable GitHub Pages
1. Go to **Settings** → **Pages** (in the left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Select **main** branch and **/ (root)** folder
4. Click **Save**

### Step 4: Visit your site
Your site will be live at: `https://YOUR-USERNAME.github.io` within 2-3 minutes.
